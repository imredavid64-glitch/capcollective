5. Check the leaderboard mechanics in `24_ENGAGEMENT_AND_GAMIFICATION_GUIDE.md`

1. Teach from `18_LESSON_PLAN_LIBRARY.md` + print `20_STUDENT_WORKSHEETS_PACK.md`

### For Scaling & Handing Off
1. Replicate to other schools via `26_DISTRICT_SCALE_AND_REPLICATION_GUIDE.md`
2. Ensure continuity with `27_CONTINUITY_AND_HANDOVER_GUIDE.md`
3. Add advanced data/AI projects from `28_DATA_SCIENCE_AND_AI_EXTENSION_GUIDE.md`

### For IoT / Firmware Deployment (FabLab+ / Center Tier)
1. Review `FIRMWARE_AND_IOT_GUIDE.md` for hardware procurement
2. Order ESP32-S3 CAM (Node 1), ESP32 (Node 2), ESP32-S3 + displays (Radio Tower)
3. Configure `RADIO_CHANNEL`, `TOWER_MAC`, WiFi, Supabase credentials
4. Flash firmware via PlatformIO (`pio run -t upload`) or Arduino IDE
5. Set up Supabase table `cap_counts` and enable realtime
6. Deploy `web/supabase_dashboard/` to Vercel/Netlify
7. Verify ESP-NOW communication: Node → Tower → Supabase → Dashboard
8. Integrate with Command Center Sheets Tab 8 (Sensor Data Log)

## 🤖 FIRMWARE & IoT SYSTEM (FabLab+ / Center Tier)

The kit includes a complete ESP32/ESP32-S3 IoT system for automated cap counting:

| Component | Hardware | Cost | Firmware |
|-----------|----------|------|----------|
| **Node 1** | ESP32-S3 CAM + Ultrasonic + Color Camera | ~$35-55 | `firmware/node1_cap_counter/` |
| **Node 2** | ESP32 + IR Beam-break / Ultrasonic | ~$15-25 | `firmware/node2_cap_counter/` |
| **Radio Tower** | ESP32-S3 + TFT + OLED + SD + Camera | ~$40-60 | `firmware/radio_tower/` |

**Architecture:** Nodes → ESP-NOW (2.4 GHz) → Radio Tower → WiFi → Supabase PostgreSQL → Real-time Dashboard

See `FIRMWARE_AND_IOT_GUIDE.md` for complete hardware specs, wiring, configuration, flashing instructions, and Supabase setup.
