    Accessibility & Inclusion Guide¶

    Ensuring Cap Collective works for every student, regardless of ability.

    Core Principle¶

    "Inclusion isn't a feature — it's the foundation. If one student can't participate, the program isn't done."

    Physical Accessibility¶

    Space Requirements¶

    Requirement Standard Cap Collective Application
    Door Width ≥32" clear All machine rooms
    Aisle Width ≥36" (48" preferred) Between all stations
    Turning Radius 60" diameter At each machine
    Reach Range 15-48" high Controls, materials, storage
    Knee Clearance 27" high × 30" wide × 19" deep Wash sink, press controls
    Floor Surface Firm, stable, slip-resistant Entire workspace

    Machine Accessibility¶

    Heat Press¶

    • Height-adjustable platform (28-34")
    • Side-loading option (not just front)
    • Controls at 40" max height
    • Tactile markers on temp/time dials
    • Foot pedal option (hands-free)
    • Mirror for viewing platen (seated)

    Shredder¶

    • Hopper at 36" max height
    • Side feed chute option
    • Push sticks at multiple lengths
    • Emergency stop at 36" height, both sides
    • Visual + auditory jam indicator

    Laser Cutter¶

    • Bed height 28-34" (adjustable)
    • Front-loading (not top)
    • Focus tool with tactile markings
    • Camera preview on external monitor
    • Emergency stop at wheelchair height

    Wash Station¶

    • Sink: 34" max height, knee clearance
    • Lever/faucet handles (not knobs)
    • Soap dispenser: touchless or lever
    • Drying rack: adjustable height
    • Non-slip mat

    Sensory Accessibility¶

    Visual¶

    Need Accommodation
    Low vision High-contrast markings (yellow/black) on all controls
    Large-print labels (18pt+) on all materials
    Magnifying glasses at each station
    Screen reader compatible dashboard (ARIA labels)
    Color blindness Color + shape + text coding (not color alone)
    Patterns on charts (not just color)
    Blindness Braille labels on critical controls
    Audio prompts for machine states
    Tactile floor markers for pathways
    Screen reader training for data analysis role

    Auditory¶

    Need Accommodation
    Hard of hearing Visual alerts (flashing lights) on all machines
    Written safety procedures at each station
    Vibration alerts on wearables (optional)
    Sign language interpreter for training
    Deafness All audio cues → visual + vibration
    Emergency: flashing strobe + vibration pager
    Machine state: LED display (not beeps)
    Buddy system for auditory cues

    Sensory Processing¶

    Need Accommodation
    Sensitivity Noise-canceling headphones (available at all stations)
    Sunglasses/FL-41 lenses for laser/press lights
    Non-latex gloves (nitrile)
    Weighted lap pad for seated work
    Quiet corner for breaks
    Seeking Fidget tools at stations
    Standing desk option
    Movement breaks scheduled

    Cognitive & Learning Accessibility¶

    Instructional Design¶

    Principle Implementation
    Multiple Means of Representation Visual + verbal + hands-on for every lesson
    Multiple Means of Action Choice: write, draw, speak, build, code
    Multiple Means of Engagement Choice of role, project, pace, partners
    Scaffolding Checklists, templates, sentence frames, models
    Chunking Break tasks into 15-min segments with checkpoints

    Specific Accommodations¶

    Executive Function¶

    • Visual timers at every station
    • Task breakdown cards (step 1, 2, 3...)
    • Color-coded workflow (green=go, yellow=check, red=stop)
    • Daily schedule posted visually
    • Transition warnings (5 min, 2 min, 1 min)

    Memory¶

    • Laminated quick-reference cards at each machine
    • Digital checklists with photos (tablet at station)
    • Peer buddy system for multi-step tasks
    • "Cheat sheets" for common procedures

    Attention¶

    • Standing desk / wobble stool option
    • Movement breaks built into schedule
    • Fidget tools at stations (silent)
    • Noise-canceling headphones available
    • Preferential seating (away from distractions)

    Language (ELL)¶

    • Bilingual labels (English + home language)
    • Visual vocabulary cards (photo + word)
    • Sentence frames for lab reports
    • Peer translator buddy
    • Translated safety cards (top 10 languages)

    Dyslexia/Dysgraphia¶

    • Dyslexia-friendly fonts (OpenDyslexic, Arial)
    • Audio versions of written materials
    • Speech-to-text for data entry
    • Oral assessment option
    • Extra time on written tasks

    Physical Disability Accommodations¶

    Wheelchair Users¶

    Station Adaptation
    Collection Boxes at 36" height, front access
    Wash Sink at 34" max, knee clearance, lever faucet
    Shredder Side feed chute at 36", push stick holder
    Press Side-load platform, foot pedal, mirror
    Laser Front-load bed at 30", camera preview
    Data Adjustable height desk, tablet mount

    Limited Fine Motor¶

    • Adaptive tools: universal cuff, built-up handles
    • Push-button controls (not dials/knobs)
    • Voice-activated data entry (tablet)
    • Magnetic tool holders
    • Peer assist for fine tasks (buddy system)

    Limited Strength/Endurance¶

    • Lightweight tools (aluminum push sticks)
    • Powered assist (electric shredder feed)
    • Scheduled rest breaks (Pomodoro: 25/5)
    • Seated option for all stations
    • Task rotation every 30 min

    One-Handed Operation¶

    • Foot pedals for press/laser
    • Clamps/vises for holding work
    • Single-handed tool changes
    • Voice commands for digital tools

    Social-Emotional Accessibility¶

    Anxiety¶

    • Preview schedule day before
    • "Safe person" designated
    • Gradual exposure to machines (observe → assist → lead)
    • Calm-down corner with sensory tools
    • Clear exit strategy for overwhelm

    Autism Spectrum¶

    • Consistent routine (same stations, same order)
    • Visual schedule with photos
    • Advance notice of changes (24 hrs)
    • Sensory profile on file (triggers, calming)
    • Special interest integration (data, design, mechanics)

    Trauma-Informed¶

    • Choice in participation level
    • No forced public speaking
    • Predictable adult responses
    • Private check-in option
    • Celebrate effort, not just output

    Inclusive Role Design¶

    Role Adaptation Matrix¶

    Role Physical Sensory Cognitive Social
    Collection Captain ☐ Seated route ☐ Quiet zones ☐ Visual schedule ☐ Partner option
    Wash Lead ☐ Accessible sink ☐ Non-latex gloves ☐ Visual steps ☐ Team of 2
    Shredder Op ☐ Side feed ☐ Noise canceling ☐ Checklist + photos ☐ Buddy system
    Press Op ☐ Side load / pedal ☐ Visual timer ☐ Color-coded dials ☐ Partner required
    Design Eng ☐ Tablet CAD ☐ Screen reader ☐ Templates ☐ Pair programming
    Data Analyst ☐ Tablet/voice ☐ Screen reader ☐ Templates ☐ Peer review
    Biz Manager ☐ Tablet POS ☐ Large print ☐ Scripts ☐ Partner sales

    Universal Design: Every Role Has¶

    • Seated option (stool at every station)
    • Partner option (no solo requirement)
    • Visual supports (photos, colors, icons)
    • Choice of output (speak, type, draw, build)
    • Flexible timing (no speed pressure)

    Inclusive Curriculum Design¶

    Lesson Plan Checklist¶

    • Objectives: Multiple pathways to mastery
    • Materials: Accessible formats (digital, large print, audio, tactile)
    • Vocabulary: Pre-taught, visual supports, bilingual glossary
    • Instruction: Chunked, modeled, guided practice, independent
    • Assessment: Choice of format (oral, visual, written, demo)
    • Extension: Open-ended for advanced learners
    • Support: Scaffolds ready (sentence frames, templates, peer)
    • Environment: Sensory-friendly, movement-friendly, choice-rich

    Example: Adapted Lesson 5 (Wash→Shred→Press)¶

    Standard Version Inclusive Version
    Teacher demos, students watch Station rotation: Each student tries each step
    Write lab report Choice: Draw comic, record video, dictate, write
    Measure with calipers Options: Digital caliper (voice), tactile caliper, photo + app
    5-min timer Options: Visual timer, vibrating timer, phone alarm
    Stand at press Option: Sit on stool, foot pedal, partner press
    Sort by color Options: Visual sort, tactile sort (textured caps), verbal sort

    Drill Accommodations¶

    • Pre-drill walkthrough (no alarm)
    • Noise-canceling headphones during drill
    • Advance notice (24 hrs for sensitive students)
    • Alternative exit route mapped
    • Buddy assigned (trained)
    • Post-drill debrief (calm space)

    Staff Training¶

    Required PD (Annual, 2 Hours)¶

    Module Time Content
    Disability Awareness 30 min Types, language, myths, legal
    UDL in Cap Collective 45 min Applying UDL to each role/station
    Assistive Tech Demo 30 min Hands-on with tools
    Emergency Procedures 15 min PEEPs, drills, communication

    Monitoring & Improvement¶

    Accessibility Audit (Quarterly)¶

    Area Metric Target Method
    Participation Rate % students with disabilities in program ≥ district avg Enrollment data
    Role Diversity % students with disabilities in each role ≥ 2 roles each Role roster
    Certification Rate % students with disabilities certified ≥ 80% of peers Cert tracker
    Satisfaction Student/parent survey (accessibility) ≥ 4/5 Annual survey
    Incidents Accessibility-related incidents 0 Incident log
    Accommodations % accommodations implemented on time 100% Accommodation log

    Student Voice¶

    • Monthly: "Accessibility check-in" (anonymous form)
    • Quarterly: Focus group (students with disabilities)
    • Annual: Co-design session (students redesign one station)

    Legal Framework¶

    Law Requirement Cap Collective Application
    IDEA FAPE, LRE, IEP Program access in IEP, related services
    Section 504 Equal access, accommodations 504 plan → machine access, role mods
    ADA Title II Program accessibility Physical + digital access
    Assistive Tech Act AT consideration AT in every IEP/504 for program
    ESSA Equitable access Title I/IV funds for access

    Documentation¶

    • Accessibility features in IEP/504 (supplementary aids)
    • Assistive technology in IEP (tools, training)
    • Physical access in 504 (room, machines, routes)
    • Communication access (AAC, interpreters, materials)
    • Emergency plan (PEEP) in health plan
