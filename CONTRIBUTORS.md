## Recognition Tiers

### 🌟 Cap Collective Champions
Major contributions: new curriculum units, hardware designs, firmware features, dashboard modules
- Listed in release notes
- Featured in annual blog post
- Invited to advisory board

### 🔧 Core Contributors
Significant improvements: documentation overhauls, bug fixes, CAD optimizations, translations
- Listed in release notes
- Contributor badge on Discord

### 🌱 Community Contributors
Any merged PR: typo fixes, small improvements, issue reports, testing
- Listed here in CONTRIBUTORS.md
- Community shoutout on Discord
