# Cap Collective — Student Role Cards & Scheduling
### Job Descriptions, Certifications & Rotation Tools

## THE 7 CORE ROLES

```
╔════════════════════════════════════════════╗
║  ROLE 1: COLLECTION CAPTAIN                ║
╠════════════════════════════════════════════╣
║  MISSION: Keep every box emptied & logged.  ║
║                                            ║
║  DUTIES:                                   ║
║  • Weekly sweep of all collection boxes     ║
║  • Weigh and log each pickup                ║
║  • Photograph for dashboard                 ║
║  • Replace bags, wipe boxes                 ║
║  • Report full boxes to Program Lead        ║
║                                            ║
║  SKILLS: Organization, reliability          ║
║  CERT: 🟡 Yellow (Collection + Wash)        ║
║  GRADES: 3+                                 ║
║  TIME: 30 min/week                          ║
╚════════════════════════════════════════════╝
```

```
╔════════════════════════════════════════════╗
║  ROLE 2: WASH STATION LEAD                  ║
╠════════════════════════════════════════════╣
║  MISSION: Ensure clean, Grade-A material.   ║
║                                            ║
║  DUTIES:                                   ║
║  • Remove silicone/foam liners              ║
║  • Soap soak, scrub, rinse until clear      ║
║  • Set caps to air-dry (24 hrs)             ║
║  • Reject contaminated caps                  ║
║  • Log rejected count                        ║
║                                            ║
║  SKILLS: Attention to detail, hygiene        ║
║  CERT: 🟡 Yellow                             ║
║  GRADES: 3+                                  ║
║  TIME: 45 min/week                           ║
╚════════════════════════════════════════════╝
```

```
╔════════════════════════════════════════════╗
║  ROLE 3: SHREDDER OPERATOR                  ║
╠════════════════════════════════════════════╣
║  MISSION: Turn caps into uniform 5-8mm flakes║
║                                            ║
║  DUTIES:                                   ║
║  • Clear blades, verify rotation            ║
║  • Feed slowly using plunger only           ║
║  • Sieve flakes for consistency             ║
║  • Store by color in labeled buckets        ║
║  • Oil blades after each session            ║
║                                            ║
║  SKILLS: Patience, machine care              ║
║  CERT: 🟠 Orange (Shredder)                  ║
║  GRADES: 6+  (min age 11)                    ║
║  TIME: 45 min/week                           ║
╚════════════════════════════════════════════╝
```

```
╔════════════════════════════════════════════╗
║  ROLE 4: PRESS OPERATOR                     ║
╠════════════════════════════════════════════╣
║  MISSION: Melt flakes into perfect sheets.  ║
║                                            ║
║  DUTIES:                                   ║
║  • Set temp (HDPE 140°C / PP 170°C)         ║
║  • Verify with IR thermometer               ║
║  • Build parchment sandwich                 ║
║  • Press 5 min → flip → press 5 min         ║
║  • Cool under weight, measure thickness     ║
║                                            ║
║  SKILLS: Precision, safety mindset           ║
║  CERT: 🔴 Red (Heat Press)                   ║
║  GRADES: 6+  (min age 11)                    ║
║  TIME: 60 min/week                           ║
╚════════════════════════════════════════════╝
```

## LEADERSHIP LADDER
Students can progress:
```
Volunteer → Certified Operator → Station Lead → Team Captain → Program Mentor
   (any learner)   (training done)   (supervises)   (leads group)   (trains others)
```
**Bonus:** Program Mentors (12th grade) earn community-service hours and reference letters.
