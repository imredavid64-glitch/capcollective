# CHAPTER 1: GETTING STARTED (Week 0-1)

## 1.1 The 5-Minute Pitch (For Admin)

> "Cap Collective is a student-run circular economy program. Students collect HDPE bottle caps from campus, process them into plastic sheets and molded products using safe, small-scale machinery, and sell those products to fund the school garden. It hits STEM standards, entrepreneurship, data science, and sustainability — all in one program. We can start for under $1,000."

**Why administrations say yes:**
- **Low floor, high ceiling** — start Core tier, scale to FabLab
- **Standards-aligned** — not a "fun extra," it's curriculum
- **Revenue-generating** — products fund other programs
- **Measurable impact** — dashboards prove value for grants/PR
- **Student-led** — builds leadership, not teacher workload

## 1.2 Admin Buy-In Checklist
- [ ] 30-min presentation (use Launch Deck, Slides 1-24)
- [ ] Identify **Program Lead** (a teacher with 2-4 hrs/week)
- [ ] Confirm **budget tier** (Core / FabLab / Center)
- [ ] Confirm **space** (see 1.3)
- [ ] Sign **Safety MOU** (Appendix A)
- [ ] Add to **school calendar** (launch week, PD dates)

## 1.3 Space Assessment
You need a room that satisfies ALL of these:

| Requirement | Why | Minimum Spec |
|-------------|-----|--------------|
| **Ventilation** | Plastic off-gassing | Window + exhaust fan (100+ CFM) OR fume hood |
| **Power** | Heat press + shredder draw | 1× 16A circuit (US: 20A), grounded |
| **Water** | Washing station | Sink within 20m, or use basins |
| **Surface** | Work tables | 3× tables, heat-resistant mats |
| **Storage** | Caps, flakes, products | Lockable cabinets (chemicals/blades) |
| **Floor** | Safety | Non-slip, easy-clean |

**If you don't have a dedicated room:** Use the art room, science lab, or makerspace on a rotating schedule. The heat press can be on a rolling cart.

## 1.4 Choosing Your Tier

### CORE ($500-1,000) — Start Here
**Includes:** Budget heat press (Transmax/Microtec), hand tools, PPE, DIY wooden boxes, manual shredder.
**Produces:** Coasters, simple sheets, keychains (basic).
**Best for:** Primary schools, after-school clubs, pilots.

### FABLAB ($2,500-5,000) — Scale Up
**Adds:** Auto-open press (Secabo TC5), Bambu Lab A1 / Prusa MK4S, Arduino sensor kits, GDPR shredder, basic CNC.
**Produces:** Full product line + custom molds + 3D filament.
**Best for:** Middle/High, makerspaces, STEM academies.

### CENTER ($10,000+) — District Hub
**Adds:** Premium press (Stahls), injection molder (SDS Injection Mini 2), Trotec laser, precision aluminum molds, industrial ventilation.
**Produces:** Architectural tiles, B2B orders, filament at scale.
**Best for:** Technical colleges, district resource centers.

- Assessment: Sequencing worksheet

**Lesson 3: Count & Graph (45 min)**
- Activity: Count this week's caps, make a class bar graph
- Extension: Predict next week's count

### 3-5: "Cap Engineers" (3 lessons)
**Lesson 4: Build the Box (90 min, double period)**
- Build a collection box from laser-cut kit
- Math: Measure, assemble, check square
- Standard: 3-5-ETS1-1

**Lesson 5: From Caps to Coaster (90 min)**
- Watch press cycle (teacher demo)
- Students design a coaster in Tinkercad
- Standard: 3-5-ETS1-2

**Lesson 6: The Numbers (45 min)**
- Weigh flakes, calculate yield, graph
- Standard: 5-PS1-3, Math 5.MD

### 6-8: "Cap Innovators" (3 lessons)
**Lesson 7: Programming the Counter (90 min)**
- Wire ESP32 + IR sensor, upload code
- Test with falling caps
- Standard: MS-ETS1-2

**Lesson 8: Life Cycle Assessment (90 min)**
- Research virgin vs recycled HDPE impact
- Build comparison dashboard
- Standard: MS-PS1-3

**Lesson 9: The Business Case (90 min)**
- Cost a product (material + labor + overhead)
- Set price, calculate margin, pitch to "investors"
- Standard: MS-ETS1-2

### 9-12: "Cap Systems Designers" (3 lessons)
**Lesson 10: Polymer Science & Rheology (90 min)**
- Test melt flow, measure shrinkage, document
- Standard: HS-PS2-6

**Lesson 11: Systems Optimization (90 min)**
- Map full workflow, find bottleneck, propose fix
- Standard: HS-ETS1-3

**Lesson 12: Grant Writing & Scale (2 periods)**
- Draft a real grant (template provided)
- Present to "board" (panel of staff)
- Standard: ELA W.9-10.1

## 3.3 Box Building (Class Activity)
**Materials per box:**
- Laser-cut plywood kit (`cad/collection_box.scad` → export DXF; final CAD to be added)
- Wood glue (1 bottle per 3 boxes)
- Clamps (4+)
- Acrylic front panel
- IR sensor + ESP32 (FabLab tier)
- Signage (printed)

**Assembly Steps (from Instructables):**
1. Glue side edges.
2. Position and attach pieces.
3. Hold panels to set (60 seconds).
4. Repeat to finish structural box.
5. Install sensor slot & acrylic.
6. Mount signage.

**Time:** 30-45 min/box with 2 students.
**Tip:** A flush box ensures IR sensors work perfectly.

## 3.4 Collection Protocol
- **Frequency:** Weekly (Fridays) minimum; daily in high-traffic zones
- **Responsible:** Collection Captain + rotating volunteers
- **Steps:**
  1. Empty box into labeled tote (by color if possible)
  2. Weigh tote (record grams)
  3. Photograph for dashboard
  4. Replace box, wipe if needed
  5. Log in Command Center → Collection Tracker tab

## 3.5 Cleaning Protocol (CRITICAL)
**This is the most important step for quality.**

1. **Sort:** HDPE #2 vs PP #5 (check underside symbol)
2. **Remove liners:** Pull out silicone/foam inner seals (they don't melt!)
3. **Soak:** Warm water + dish soap, 10 min
4. **Scrub:** Old toothbrush for stubborn residue
5. **Rinse:** Until water runs clear
6. **Dry:** Air dry 24 hours on mesh (no towel — lint!)
7. **QC:** Any cap with adhesive/paper/liquid smell → reject

> **Why:** Residual milk/sugar burns at high temp → toxic fumes + discolored product.

## 3.6 Shredding SOP (Grade 6+, Certified)
1. Clear blades of residual plastic
2. Toggle motor, verify rotation
3. **Feed slowly** — do not overfeed (stalls motor)
4. Target flake size: 5-8mm
5. Sieve through mesh screen (consistency)
6. Store in labeled buckets by color
7. Oil blades after each session

## 3.7 Heat Press SOP (Grade 6+, Certified)
**HDPE Settings:** 140°C | **PP Settings:** 170°C

1. Turn on press, set temp & time
2. Wait for platen to reach FULL temp (verify with IR thermometer)
3. **Parchment sandwich:** flakes between two baking-paper sheets
4. Press 5 min → **flip** → press 5 min
5. Cool under weight (prevents warping)
6. Remove, measure thickness

> ⚠️ **WARNING:** Never let plastic touch the metal platen. Monitor constantly — thermal runaway is possible.

## 3.8 Role Rotation Schedule
Rotate every **2 weeks** so all students experience multiple roles.

| Week | Collection | Wash | Shred | Press | QC | Data |
|------|-----------|------|-------|-------|-----|------|
| 1-2 | Group A | Group B | Group C | Group D | Group E | Group F |
| 3-4 | Group B | Group C | Group D | Group E | Group F | Group A |
| 5-6 | ... | ... | ... | ... | ... | ... |

## 5.3 Mold Design (Fusion 360)
1. Design part (student CAD)
2. Create two-part mold with **gates** (plastic entry) and **vents** (air escape)
3. Fabricate: CNC mill or 3D print
4. Apply **release agent** before use

**Key principle:** Design **mono-material** products (single polymer) so they can be re-shredded.

## 5.4 Quality Control Standards
See Launch Deck Slide 27. Every batch gets a QC sheet (Appendix C).

**Rejection causes & fixes:**
| Defect | Cause | Fix |
|--------|-------|-----|
| Voids/bubbles | Uneven flake size | Sieve more, pre-mix |
| Warping | Cooled too fast | Cool under weight |
| Burn marks | Temp too high | Lower to 140°C, monitor |
| Weak product | Mixed polymers | Sort strictly by #2/#5 |
| Rough edges | No sanding | Sand with 120→400 grit |

## 6.2 Sensor Setup (FabLab+)
**Hardware:** ESP32 + IR beam-break sensor
**Wiring:**
```
IR Sensor VCC → ESP32 3.3V
IR Sensor GND → ESP32 GND
IR Sensor OUT → ESP32 GPIO 27
IR Sensor on chute opposite a small IR LED (or use reflective)
```
**Logic:** When beam breaks → increment counter → send to dashboard via WiFi/HTTP.

**Code:** Included in Resources (`sensor_count.ino`).

## 6.5 CO₂e Calculation
```
CO₂e avoided = (mass of HDPE diverted in kg) × 1.9 kg CO₂e/kg
Source: EPA WARM model (conservative estimate for HDPE recycling vs landfill)
```
*Example: 35 kg diverted × 1.9 = 66.5 kg CO₂e avoided ≈ 165 miles not driven.*

## Appendix E: Troubleshooting FAQ
| Problem | Solution |
|---------|----------|
| Caps won't melt evenly | Sieve flakes; ensure uniform size |
| Product warps | Cool under weight; slow cooling |
| Strong smell | Lower temp; check ventilation; clean caps |
| Sensor miscounts | Adjust beam alignment; add debounce code |
| Shredder jams | Feed slower; clear blades; don't overfeed |
| Mold sticks | Apply release agent; cool longer |
| Low participation | Add competition; show dashboard publicly |
| No admin support | Use revenue + standards angle in Launch Deck |
| Equipment breaks | See warranty; keep spare parts list |
| Grant rejected | Ask for feedback; reapply; use templates |

## Appendix F: Glossary
- **HDPE:** High-Density Polyethylene (Plastic #2) — caps
- **PP:** Polypropylene (Plastic #5) — lids, cups
- **PET:** Polyethylene Terephthalate (Plastic #1) — bottles
- **Flake:** Shredded plastic pieces (5-8mm)
- **Feedstock:** Material input to the melt process
- **Mono-material:** Single-polymer product (recyclable)
- **Gates/Vents:** Mold channels for plastic entry/air exit
- **LCA:** Life Cycle Assessment
- **CO₂e:** Carbon dioxide equivalent
- **Beam-break:** Sensor that counts when a beam is interrupted
