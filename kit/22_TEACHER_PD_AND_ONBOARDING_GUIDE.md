# Cap Collective — Teacher Professional Development & Onboarding Guide
### Get Any New Teacher Running the Program in One Afternoon
**Includes a 2-hour PD agenda, a self-paced onboarding path, and a substitute-teacher one-pager.**

---

# PART 1: THE 2-HOUR PD SESSION

**Audience:** Any teacher/staff who will support the program.
**Outcome:** Leave able to run a lesson, supervise a station, and access all tools.

## Agenda
| Time | Segment | Led by |
|------|---------|--------|
| 0:00-0:10 | Welcome + why this matters | Program Lead |
| 0:10-0:25 | Program overview + data walkthrough | Lead |
| 0:25-0:45 | **Station rotation round 1** (hands-on) | Lead |
| 0:45-1:05 | **Station rotation round 2** | Lead |
| 1:05-1:15 | Break | — |
| 1:15-1:35 | Safety deep-dive (PPE, limits, emergencies) | Safety officer |
| 1:35-1:55 | Teaching with the kit (lesson demo) | Master teacher |
| 1:55-2:00 | Q&A, next steps, sign-up | Lead |

## Station Rotation (hands-on)
Set up 4 stations; teachers rotate in 20 min (10 min each shown twice):
1. **Collect & Sort** — material ID drill
2. **Wash & Dry** — the washing SOP
3. **Shred** — safe operation demo
4. **Press** — watch a full cycle

## PD Success Criteria
☐ Can identify HDPE vs PP vs reject
☐ Can demonstrate correct PPE
☐ Can find every SOP and form
☐ Can log data in the Command Center
☐ Knows who to call in an emergency

# PART 3: FACILITATOR'S GUIDE (for the Program Lead running PD)

## Before the Session
```
☐ Book the room + the workshop space
☐ Confirm safety officer attendance
☐ Print: agenda, handouts, safety quiz, onboarding checklist
☐ Stage 4 stations (see Part 1)
☐ Test the projector + dashboard
☐ Coffee/snacks (attendance boost!)
```

## Facilitation Tips
- **Show, don't tell.** Every concept → a demo.
- **Address fear first.** Teachers worry about safety liability — spend real time here.
- **Make it easy.** Emphasize "run a lesson straight from the book."
- **Get commitment.** End with each teacher picking their first action.

## Handling the Top 5 Teacher Concerns
| Concern | Response |
|---------|----------|
| "This adds to my workload." | "The kit is turnkey. Start with 1 lesson + 1 station. Students run the rest." |
| "Is it safe?" | "Every machine has an SOP, a quiz, and a certification card. No cert, no machine." |
| "I'm not technical." | "Videos + scripts + a sub one-pager. If you can follow a recipe, you can run this." |
| "What if it fails?" | "We pilot small. We measure. We improve. Worst case, we recycle caps the normal way." |
| "Who pays?" | "Tier 1 is under $1,000; grants and the Eco-Store cover the rest. See the finance playbook." |

# PART 5: COACHING & MENTORSHIP MODEL
- **Buddy system:** New teacher paired with an experienced one for the first month.
- **Open-door sessions:** Anyone may observe a running session.
- **Micro-PD:** 15 min at staff meetings — one tip per week.
- **Lesson lab:** Teachers co-plan one lesson per term.
- **Recognition:** Shout-outs at staff meetings; reference in newsletters.

# PART 7: ONBOARDING A MID-YEAR TEACHER (Fast Track)
1. Watch assembly video + 3-min overview (15 min)
2. Read this guide's 1-pager (10 min)
3. Pass the general safety quiz (15 min)
4. Shadow one full session (1 session)
5. Co-lead one lesson (1 session)
6. Take over with buddy available (ongoing)

**Total:** about 2 hours of reading + 2 sessions of shadowing.
