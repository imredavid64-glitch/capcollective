# Cap Collective — District Scale & Replication Guide
### Go From One School to a Whole District (Without Breaking)
**Readiness assessment, hub-and-spoke model, train-the-trainer, shared services, and a 12-month rollout.**

---

# PART 1: WHEN TO SCALE (Don't Rush)
**You're ready to replicate when:**
☐ Program has run ≥1 full semester
☐ You have documented, working SOPs (this kit)
☐ You have **measured** impact (real numbers)
☐ At least 2 staff can run it without you
☐ You have a repeatable launch playbook (`19_...`)

**Do NOT scale if:** it depends on one hero teacher, you have no data, or safety is shaky.

# PART 3: THE HUB-AND-SPOKE MODEL
**One "hub" school owns the expensive/rare equipment; "spoke" schools share it.**

```
                ┌──────────────┐
                │   DISTRICT    │
                └──────┬───────┘
                       │
        ┌──────────────┼──────────────┐
        │              │              │
   ┌────▼────┐   ┌────▼────┐   ┌────▼────┐
   │  HUB    │◄──│ SPOKE A │──►│ SPOKE B │
   │(shared  │   │(collect)│   │(collect)│
   │ equip)  │   └─────────┘   └─────────┘
   └─────────┘
```
- **Spokes** do collection, sorting, washing (cheap, safe).
- **Hub** does melting/pressing/injection (expensive, needs ventilation + certification).
- Caps flow to the hub; finished products flow back for sale.
- **Shared van/runner** moves material weekly or bi-weekly.

**Benefits:** 1 machine set serves 5-10 schools; each spoke needs only ~$500 Tier-1.

# PART 5: TRAIN-THE-TRAINER MODEL
1. **Hub trains 2 trainers per spoke** (3-4 hr session using `22_...`).
2. Trainers certify their own staff **and** students.
3. Hub provides ongoing coaching (monthly call).
4. **Certification is portable:** a certified teacher can train at any site.
5. Keep a **district trainer registry** (shared sheet).

```
DISTRICT TRAINER REGISTRY
Name | Home site | Certified on | Trained-by | Expiry
-----|-----------|--------------|------------|--------
```

# PART 10: BRAND vs AUTONOMY
- **Shared (consistent):** name, logo, safety rules, core SOPs, metrics, curriculum.
- **Local (flexible):** product designs, campaigns, local partnerships, pricing tweaks.
- Give each site a **toolkit** and a **charter template** (`12_...`).

---

# PART 11: BENCHMARKING (Compare Sites Fairly)
| Metric | Formula | Good |
|--------|---------|------|
| Caps per student | caps ÷ enrollment | 20+/term |
| Weight per student | kg ÷ enrollment | 0.05 kg/term |
| Yield | product ÷ flake | 85%+ |
| Certifications rate | cert ÷ roster | 30%+ |
| Revenue per site | $ | $500+/term |
| Engagement | active ÷ roster | 40%+ |

**Normalize per-student** — never rank a small school against a large one by raw totals.

---

# PART 12: COMMON SCALING PITFALLS
| Pitfall | Prevention |
|---------|-----------|
| Hero-teacher dependency | Require 2+ trained staff per site |
| Safety drift | Central re-certification audits |
| Data mess | One dashboard, one schema, central training |
| Equipment bottlenecks | Hub capacity planning; schedule slots |
| Uneven funding | Central fundraising; per-site equity |
| Brand chaos | Style guide + charter |
| Neglecting maintenance | Budget for service from day one |
| Scaling too fast | 3 schools at a time, max |
