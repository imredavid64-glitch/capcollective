# GRADE BAND K-2 — "CAP DETECTIVES"

## LESSON K1: What Are Plastic Caps? (45 min)
**Objective:** Students classify caps by observable properties and identify that caps differ from bottles.
**Standards:** K-ESS3-3, 2-PS1-1
**Materials:** Pile of mixed caps, magnifiers, sorting mats, worksheet K1
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-5 | Hook: Hold up a bottle and a cap. "Are these the same?" |
| 5-15 | Explore: Students handle caps — feel, look, smell (clean ones only) |
| 15-30 | Sort: By color, then by size, then by "bumpy/smooth" |
| 30-40 | Share: Each group explains ONE way they sorted |
| 40-45 | Wrap: "Caps and bottles are different. That's why we keep caps separate." |
**Differentiation:** EAL — picture cards; advanced — sort by 3 attributes.
**Assessment:** Sorting worksheet K1 (correct classification).
**Extension:** Count a cup of caps; graph as a class.

## LESSON K2: Cap's Journey (45 min)
**Objective:** Students sequence where a cap can go and explain why recycling is better.
**Standards:** K-ESS3-3
**Materials:** "Cap's Journey" story, sequence cards, glue
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-10 | Read "Cap's Journey" aloud (Printable Resources) |
| 10-25 | Sequence cards: bottle → bin → (ocean OR box → coaster) |
| 25-35 | Act it out — students play roles |
| 35-45 | Discuss: "Which path is better? Why?" |
**Assessment:** Correctly sequence 5 cards.
**Extension:** Draw your own "good journey" for a cap.

## LESSON K3: Count & Graph (45 min)
**Objective:** Students count collected caps and represent data in a bar graph.
**Standards:** K.CC.B.4, 1.MD.C.4, 2.MD.D.10
**Materials:** This week's caps, graphing paper, sticky dots
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-10 | Count caps as a class (every 10th one a different color) |
| 10-30 | Build a class bar graph by color |
| 30-40 | "Which color won? How many more?" |
| 40-45 | Predict next week's total |
**Assessment:** Graph correct; answers comparison questions.
**Extension:** Set a class goal for next week.

# GRADE BAND 3-5 — "CAP ENGINEERS"

## LESSON E1: Build the Box (90 min, double period)
**Objective:** Students assemble a collection box and explain how it works.
**Standards:** 3-5-ETS1-1, 3.MD.B.4
**Materials:** `cad/collection_box.scad` cut parts, glue, clamps, acrylic, screws
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-10 | Show CAD design; explain finger/screw joints |
| 10-20 | Measure and check all parts present |
| 20-70 | Assemble: glue edges, clamp, screw, set 60s per joint |
| 70-85 | Install acrylic window; test drop slot |
| 85-90 | Reflect: "What would you change about the design?" |
**Differentiation:** Roles — measurer, gluer, clamp-holder, checker.
**Assessment:** Box is square, flush, functional; design reflection.
**Extension:** Design a sign for the box.

## LESSON E2: From Caps to Coaster (90 min)
**Objective:** Students trace the melt process and design a coaster in Tinkercad.
**Standards:** 3-5-ETS1-1/2, 5-PS1-3
**Materials:** Pre-made flakes, heat press (teacher demo), Tinkercad, worksheet E2
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-15 | Safety briefing + watch teacher run a press cycle |
| 15-30 | Measure flakes (weight), predict sheet thickness |
| 30-70 | Design a coaster in Tinkercad (circle + pattern) |
| 70-85 | Export DXF; compare designs |
| 85-90 | Reflect: "How did the plastic change? Why?" |
**Assessment:** Design file exported; states states-of-matter change.
**Extension:** Design a matching keychain.

## LESSON E3: The Numbers (45 min)
**Objective:** Students calculate yield and graph collection data.
**Standards:** 5-PS1-3, 5.MD.A.1, 5.NF.B.3
**Materials:** Scale, calc sheets, graph paper
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-10 | Weigh flakes; record grams |
| 10-25 | Calculate yield: grams of product ÷ grams of flakes |
| 25-40 | Graph weekly collection counts |
| 40-45 | Discuss: "What affects yield?" |
**Assessment:** Correct yield %; graph accurate.
**Extension:** Predict weight of a full box.

# GRADE BAND 6-8 — "CAP INNOVATORS"

## LESSON I1: Programming the Counter (90 min)
**Objective:** Students wire and program an IR beam-break counter.
**Standards:** MS-ETS1-2, MS-PS4-2
**Materials:** ESP32, IR sensor, jumper wires, laptop, Arduino IDE, `sensor_count.ino`
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-15 | Explain beam-break sensing; show wiring diagram |
| 15-40 | Wire ESP32 + sensor; verify with serial monitor |
| 40-70 | Upload code; test with falling caps; adjust debounce |
| 70-85 | Troubleshoot miscounts; document |
| 85-90 | Reflect: "What causes false counts? How did you fix it?" |
**Differentiation:** Pair stronger coders with beginners; provide filled-in code as scaffold.
**Assessment:** Working counter; documentation of fix.
**Extension:** Add fill-level alert at 90%.

## LESSON I2: Life Cycle Assessment (90 min)
**Objective:** Students compare environmental impact of recycled vs virgin HDPE.
**Standards:** MS-PS1-3, MS-LS2-5
**Materials:** Research links, worksheet I2, Command Center
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-15 | Define LCA stages: raw → production → use → disposal |
| 15-45 | Research: energy & CO₂ for virgin vs recycled HDPE |
| 45-75 | Build comparison table; calculate our CO₂e avoided |
| 75-90 | Present findings; debate: "Is recycling worth it?" |
**Assessment:** Accurate data; evidence-based argument.
**Extension:** LCA for PP or aluminum.

## LESSON I3: The Business Case (90 min)
**Objective:** Students cost a product and set a price to make a profit.
**Standards:** MS-ETS1-2, 7.RP.A.1, 6.RP.A.1
**Materials:** Calculator, worksheet I3, cost data
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-15 | Explain cost components (material, overhead, labor) |
| 15-45 | Cost 2 products using the formula |
| 45-70 | Set price (cost ×3); calculate margin; compare to retail |
| 70-90 | "Investor pitch" — 2 min per team to a panel |
**Assessment:** Correct costing; persuasive pitch.
**Extension:** Build a break-even model in Sheets.

# GRADE BAND 9-12 — "CAP SYSTEMS DESIGNERS"

## LESSON S1: Polymer Science & Rheology (90 min)
**Objective:** Students measure how HDPE flows and shrinks, and explain processing implications.
**Standards:** HS-PS2-6, HS-PS1-3
**Materials:** Flakes, press, calipers, IR thermo, worksheet S1
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-20 | Polymer basics: chains, amorphous vs crystalline, Tg/Tm |
| 20-50 | Experiment: melt at 130/140/150°C; measure flow & surface |
| 50-70 | Measure shrinkage after cooling; calculate % |
| 70-90 | Analyze: what processing temp gives best result? Why? |
**Assessment:** Data table; justified conclusion.
**Extension:** Test PP (higher Tm) and compare.

## LESSON S2: Systems Optimization (90 min)
**Objective:** Students map the full workflow, identify a bottleneck, and propose a data-backed fix.
**Standards:** HS-ETS1-3, HSS.ID.B.6
**Materials:** Command Center data, timer, worksheet S2
**Procedure:**
| Min | Activity |
|-----|----------|
| 0-20 | Map the process (flowchart) with cycle times |
| 20-45 | Collect timing data for each step (hands-on) |
| 45-70 | Find the bottleneck; propose a fix; predict impact |
| 70-90 | Present & critique proposals |
**Assessment:** Correct bottleneck ID; quantified improvement.
**Extension:** Implement and re-measure (A/B).

## LESSON S3: Grant Writing & Scale (2 periods)
**Objective:** Students write a real grant application to fund expansion.
**Standards:** W.9-10.1, HS-ETS1-3
**Materials:** `08_GRANT_...` templates, Command Center impact data
**Procedure (P1):**
| Min | Activity |
|-----|----------|
| 0-15 | Analyze a real grant call; identify criteria |
| 15-45 | Draft need + approach sections |
| 45-90 | Draft outcomes + budget (use our real data) |
**Procedure (P2):**
| Min | Activity |
|-----|----------|
| 0-30 | Finish + peer review against rubric |
| 30-70 | Present to a "board" (staff panel) |
| 70-90 | Revise and submit best application for real |
**Assessment:** Complete application; meets funder criteria.
**Extension:** Submit to an actual funder.
