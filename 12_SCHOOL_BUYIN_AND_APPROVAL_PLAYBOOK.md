# Cap Collective — School Buy-In & Approval Playbook
### The Complete Institutional Process: From Idea to Signed Approval
**For the Program Lead | Covers Principal, Finance, Risk/Insurance, IT, Facilities, Staff & Parents**

---

## THE BIG PICTURE: THE APPROVAL MAP
Most programs die not from bad ideas but from **skipped institutional steps**. Work this map in order.

```
┌─────────────────────────────────────────────────────────────┐
│  1. SPONSOR      → Find an admin champion (Principal/AP)      │
│  2. INFORM       → Brief leadership with the Launch Deck      │
│  3. VALIDATE     → Risk/Insurance reviews the risk register   │
│  4. RESOURCE     → Facilities confirms space/power/venting    │
│  5. FUND         → Finance approves budget / picks source     │
│  6. FORMALIZE    → Sign the MOU + program charter            │
│  7. COMMUNICATE  → Staff, parents, students                  │
│  8. LAUNCH       → Execute                              │
└─────────────────────────────────────────────────────────────┘
```
**Time to approval:** typically **3–8 weeks** depending on meeting cadence.

---

## STEP 1: FIND YOUR SPONSOR
You need **one senior advocate**. Without it, nothing moves.

**Best candidates:** Principal, Assistant Principal, STEM/Curriculum Coordinator, Head of Science, Sustainability Lead.

**How to ask:**
> "I have a proposal that hits our STEM and sustainability goals, is student-led, and can be self-funding. Can I get 20 minutes to walk you through it?"

**What they need from you:** the 30-second pitch + the Admin Quick-Start one-pager.

---

## STEP 2: BRIEF LEADERSHIP
**Format:** 20-minute slot at an existing leadership/curriculum meeting (don't ask for a special meeting first).

**Prepare:**
- Launch Deck (Slides 1-24 for admin audience)
- Admin Quick-Start Checklist (printed, one per person)
- The one-line outcome: *"10,000 caps diverted, 50 students certified, $500 revenue, $1,000 startup."*

**Ask for:** in-principle approval to explore + a named finance/risk contact.

**Sample agenda:**
| Min | Item |
|-----|------|
| 0-5 | The problem + the bridge (Deck 1-5) |
| 5-12 | The system + products + safety (Deck 6-17) |
| 12-17 | Cost, timeline, impact (Deck 18-21) |
| 17-20 | The ask + next steps |

---

## STEP 3: RISK & INSURANCE (Do NOT skip)
This is where programs fail. Get ahead of it.

**Send the insurer/risk officer:**
1. The completed Risk Assessment (Safety file, Section 4)
2. The Safety MOU (Safety file, Appendix A)
3. The machine SOPs (Safety file, Section 2)
4. Certification process (Safety file, Section 5)

**Anticipated questions & answers:**
| Question | Answer |
|----------|--------|
| "What if a student is burned?" | Temperature capped 200°C; gloves rated 500°F; 1 adult per 4 students; first aid on site; incident reporting within 24h. |
| "Is the equipment certified?" | All equipment CE/UL-certified; no homemade heating elements (except low-voltage sensor kits). |
| "What about fumes?" | Only clean HDPE/PP at ≤200°C; active ventilation mandatory; no PVC ever. |
| "Who supervises?" | Certified staff only; students certified before access. |
| "Is this covered by our liability policy?" | [Confirm with insurer — submit documents; most school liability policies cover supervised curricular activities.] |

**Outcome needed:** written confirmation that the activity is covered (or a rider added).

---

## STEP 4: FACILITIES / SPACE
**Submit a facilities request** (form in Forms Pack) for:
- Ventilated room (window + exhaust) or fume hood
- 1× 16A/20A grounded circuit
- 3 tables, storage cabinet, sink access
- Non-slip floor, fire extinguisher, first-aid

**Walk-through checklist:** photograph the room, test the exhaust (tissue test), confirm the breaker, measure the door width (equipment delivery!).

---

## STEP 5: FINANCE / FUNDING
**Meet the bursar/business manager** with:
- The budget tier (Core/FabLab/Center)
- The Command Center Procurement tab (itemized)
- Funding source options table

**Key questions they'll ask:**
| Question | Your answer |
|----------|-------------|
| "What's the total?" | "$___ startup (see itemized list)" |
| "One-time or recurring?" | "Startup is one-time; ~$___/yr consumables, covered by product revenue." |
| "Which budget code?" | "[STEM / Art / Sustainability / Dept budget — ask them]" |
| "Do you need a PO?" | "Yes — I'll submit a requisition (form attached)." |
| "Can you fundraise instead?" | "Yes — but grants take 2-6 months; a small budget line launches us now." |
| "Will it cost us money long-term?" | "No — it's designed to be self-funding within [X] months." |

**Then follow the Payment Playbook (`13_...`) to actually transact.**

---

## STEP 6: IT & DATA PRIVACY
**Only relevant if using sensors/dashboards.** Meet IT with this:

**What we need:**
- WiFi access for IoT devices (ESP32) — a dedicated/guest VLAN if possible
- Permission to use Google Workspace (Sheets) for data
- Optional: subdomain or hosting for the website (school policy-dependent)

**Privacy posture:**
- No student personal data required for the core program
- Collection data is aggregate (counts, weights)
- Student names appear only in internal role/certification sheets (access-controlled)
- Public dashboard shows **aggregates only** (never names)

**Say:** "We can run the program 100% offline (manual counting) if IT prefers. Sensors are optional."

## STEP 7: FORMALIZE — THE PROGRAM CHARTER & MOU
Sign two documents:
1. **Safety MOU** (Safety file, Appendix A) — between school and program lead
2. **Program Charter** (below) — defines scope, roles, money, success

## STEP 8: COMMUNICATE (Internal Buy-In)
You need staff and parents on board BEFORE launch to avoid resistance.

### Staff briefing (5 min at a staff meeting)
> "We're launching a student recycling program. It won't add to your workload—students run it. It maps to [standards] and is funded by [source]. Here's how your classes can plug in. Questions?"

**Handle the two real objections:**
- *"Whose class time is this?"* → "Optional enrichment + a few double periods we'll coordinate with you."
- *"Will my room get messy/noisy?"* → "No—processing happens only in the designated vented room."

### Parent communication
Use the newsletter + permission slip (Printable Resources + Forms Pack). Include safety info proactively.

### Student launch
Assembly + application form + first "Cap Drop" ceremony.

## OBJECTION HANDLING MASTER TABLE

| Objection | Response |
|-----------|----------|
| "Too expensive" | "$500-1,000 startup; self-funding after; grants available." |
| "Too risky" | "Certified operators, capped temps, supervision, full risk register, insurance confirmed." |
| "No space" | "One vented room, one period/week; rotates through existing rooms." |
| "No time" | "Pre-written lessons; student-led; 2-4 hrs/week for the lead." |
| "It'll fizzle out" | "River of revenue + curriculum = permanent; next cohort trained." |
| "Smells/fumes" | "Clean HDPE only, ≤200°C, active ventilation, no PVC." |
| "Kids will cut themselves" | "Guards, training, tool-based feeding, first aid." |
| "District won't allow it" | "We've packaged it for review: SOPs, risk register, insurance, data policy." |
| "Not our priority" | "It advances [STEM/sustainability/wellbeing goals] and generates PR/revenue." |
| "Why caps, not bottles?" | "Caps are the highest-value, most-missed item; bottles are already handled." |
